# docker_host_add.sh 风格统一重构设计

日期：2026-06-26
关联文件：`docker_host_add.sh`（待改）、`docker_host_list.sh`（风格基准）

## 背景与目标

`docker_host_list.sh` 是纯展示脚本，拥有一套完整的配色体系与方框表格渲染（perl 宽度计算），视觉统一美观。`docker_host_add.sh` 是交互脚本（输入校验、PHP 版本选择、框架选择、建目录、写 nginx 配置、写 hosts、重启 nginx），当前输出朴素，仅有零散的黄/红 ANSI。

目标：在保持 `add.sh` 现有功能不变的前提下，按 `list.sh` 的风格与配色做一次完整翻新（用户选择"较大重构"），统一视觉、优化交互呈现，并顺带加固若干健壮性问题。

采用**方案 C（混合）**：
- 交互提示、分段标题、报错/成功/警告提示 → 纯 Bash 辅助函数（无需对齐）。
- 需要精确对齐的方框卡片（选择列表、创建前确认卡片、结果摘要卡片）→ 复用 `list.sh` 的 perl 宽度计算渲染（CJK/全角宽度精确处理）。

## 设计

### 1. 配色与视觉规范

直接复用 `list.sh` 的调色板，保证两脚本视觉统一：

```
C_RESET   复位
C_TITLE   亮青   标题
C_ACCENT  亮品红 强调
C_CYAN    青     标签/边框
C_GREEN   绿     成功/启用
C_YELLOW  黄     警告/提示
C_DIM     暗灰   次要/分隔线
C_MAGENTA 紫     代理/特殊
C_LABEL   浅蓝   字段名
C_VALUE   白     字段值
```

统一语义：
- 报错：`C_ACCENT` + `❌`
- 成功：`C_GREEN` + `✅`
- 警告：`C_YELLOW` + `⚠️`
- 标题：`C_TITLE` + `▰▰▰  标题  ▰▰▰`，下方接一条 `C_DIM` 分隔线（与 `list.sh` 标题区一致）

### 2. 辅助函数（纯 Bash）

集中管理颜色与提示样式，替换现有散落的 `echo -e "\033[..."`：

- `section "标题"`：打印 `▰▰▰ 标题 ▰▰▰` + 暗灰分隔线
- `ask "提示"`：青色/带图标的问题行（配合 `read`）
- `err "msg"` / `ok "msg"` / `warn "msg"` / `info "msg"`：统一前缀图标与配色
- `kv "字段" "值"`：浅蓝字段名 + 白色值，行内展示

### 3. 交互流程（功能不变，重构呈现 + 加固）

阶段顺序不变，每段加 `section` 标题：

1. 输入采集（文件夹名 / 域名 / 备注）
   - 文件夹名、域名：仍校验"非空 + 无空格"
   - 备注：放宽为仅"非空"（允许空格）
   - 错误计数超 5 次退出逻辑保留
2. PHP 版本选择：用方框列表展示（第 5 节），输入校验保留
3. 框架选择：方框列表展示（含 `0. 无需配置`），输入校验保留
4. 加固点：
   - `sed` 替换对变量做必要转义，避免特殊字符破坏替换
   - hosts 重复判断改用更精确匹配（参考 `list.sh` 的 `grep -F`），避免子串误判（如 `a.com` 误匹配 `aa.com`）
   - macOS/Linux sed 兼容函数 `run_sed` 保留

### 4. 创建前确认卡片（perl 对齐）

采集完所有输入后、真正动手前，用 perl 渲染对齐方框卡片，展示将创建的配置：

```
▰▰▰  确认创建  ▰▰▰
┌──────────┬─────────────────────────┐
│ 文件夹    │ myblog                  │
│ 域名      │ blog.test               │
│ 备注      │ 我的博客系统             │
│ PHP版本   │ php8.2                  │
│ 框架      │ laravel.conf            │
│ 项目路径  │ /xxx/www/myblog         │
└──────────┴─────────────────────────┘
继续创建? [0. 取消 / 1. 确认]
```

含中文字段，用 `list.sh` 的宽度计算逻辑精确对齐。选 0 退出，不做任何写操作。

### 5. 选择列表卡片（perl 对齐）

PHP 版本 / 框架选择列表用同一套 perl 渲染成带序号的小方框表（青色表头 + 白色值）。定稿采用方框样式以与 `list.sh` 统一。

### 6. 结尾结果摘要卡片

创建成功后，用 `C_GREEN` 标题 `🎉 创建成功` + 一张摘要卡片（内容同确认卡片，附加一行 `hosts 状态：已添加 / 已存在`）收尾。

## 不做的事（YAGNI）

- 不改变脚本采集的输入项与最终写入的文件/目录行为（除上述明确的备注放宽、健壮性加固外）。
- 不引入额外依赖（perl 已被 `list.sh` 使用，环境一致）。
- 不做无关重构。

## 测试/验证

- `bash -n docker_host_add.sh` 语法检查通过。
- 手动走查：正常创建、文件夹已存在、框架选无、hosts 已存在、确认时取消等分支输出正常且方框对齐（含中文字段）。
